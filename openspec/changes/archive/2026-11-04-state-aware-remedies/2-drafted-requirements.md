# Requirements — drafted: the block names its speaker, its state, and its offender; the research window closes in the void

## Done when

- The declare remedy names the speaker: relay-to-the-human copy, assistant-never-declares stated in the block itself (retires Idea Q5's ambiguity).
- A declare phrase in an assistant message produces a `self-declare.v1` fact and the next block carries a one-shot correction note (retires Q1 of the how-might-we's).
- The create remedy names the resolvable schemas (single: `--schema spec`; multiple: joined; none: placeholder) (retires the placeholder question).
- A refused bash compound carries a why-line naming the offending segment, plus "read-only commands still pass".
- With no active change, research instruments block inside any repo with a local `openspec/`, with the same state-aware remedies (focus → create → declare); the "clear the focus" escape line is retired; research outside an openspec repo stays free.
- 155+ tests green, `just lint` (vocabulary law) holds, `./example/try.sh` passes end to end.
- A fresh cold-agent walk (walk #3) shows none of walk #2's five flails recurring.

## Scope

- `src/gate.ts` (block builder, declare latch + assistant noticing, research window), `src/classifier.ts` (offender capture), `src/schema.ts` (`scanSchemaNames`), `src/facts.ts` (self-declare fact), `index.ts` doc comment, tests, README + example README, CHANGELOG Unreleased.

## Out of Scope

- bin/ (CLI) — the fixes are extension-side; the CLI block copies are unaffected.
- The `mission` schema and all schema data — untouched; vocabulary stays data.
- gate-spanned-agents, terminal-only-approvals — separate open changes.
- Any block-copy localization/verbosity budget beyond the lines added.

## Guardrails

- The vocabulary law holds: no flow words (mission, step-words, grant verbs of shipped schemas) in engine source — enforced by `just lint` and the grep-proof test.
- The gate's philosophy is unchanged: never permission, always accounting; research-blocking is accounting-with-remedies, keyed on project-local `openspec/` presence only (never global-home schema resolution — that would gate every directory on the machine).
- The declare latch semantics are unchanged: user messages only, one mutation, one debt line.
- Process ruling recorded: the human disarmed the gate at idea stage (2026-10-27, host-level — repo config.json still reads `enabled: true`); work proceeded ungated by human ruling; artifacts written as the honest record, receipts in real commits.
